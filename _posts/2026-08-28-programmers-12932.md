[문제: 자연수 뒤집어 배열로 만들기](https://school.programmers.co.kr/learn/courses/30/lessons/12932?language=python3)

## 접근방법

주어진 정수를 어떻게 뒤집을 것인가가 포인트.

만약 주어진 개체가 iterable하다면, 슬라이싱을 이용해 쉽게 주어진 배열을 뒤집을 수 있다.

## Solution

n이 정수로 주어지므로 `str(n)` 으로 iterable 객체로 바꾼 뒤, `[::-1]` 로 슬라이싱한다.

이후 문자열을 순회 시 정수로 바꿔서 빈 배열에 append하고 반환하면 된다.

```python3
def solution(n):
    answer = []
    for c in str(n)[::-1]:
        answer.append(int(c))
    return answer
```

## Solution 2

수학적으로 접근해보자.  

주어진 정수의 가장 작은 자리 숫자부터 배열에 append하면 된다.  

과정1: 정수 $n$의 가장 작은 자리 숫자는 10으로 나눈 나머지로 알 수 있다. (`'일의 자리 숫자' = n%10`)

시행 후 나머지를 버리고 몫만 남기면, 과정 1을 재시행할 때 다시 제일 작은 자리 숫자를 구할 수 있다. (`'구한 숫자 버림' = n//10`)

```python3
def solution(n):
    answer = []
    
    while n>0:
     answer.append(n%10) #마지막 숫자 append
     n = n//10 #기존 숫자에서 제거
     
    return answer
```

## 시간복잡도  

두 풀이 모두 시간복잡도는 $$O(n)$$이다.
